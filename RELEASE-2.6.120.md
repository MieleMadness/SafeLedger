# SafeLedger 2.6.120 — User Guide and PDF Documentation Update

**Documentation-only patch:** the encrypted vault format, Argon2id and AES-256-GCM behavior, executable runtime logic, and all previous security fixes are unchanged.

- Published **docs/USER_GUIDE.md** as the maintained how-to guide and technical field manual.
- The Windows Portable release's packaged `README.pdf` now renders that dedicated guide instead of embedding the old release-history-heavy GitHub README.
- Reorganized practical how-tos: first launch and portable installation, Profile and Wallet/Account/Asset workflow, offline icons and settings, Recovery Intelligence/Test Recovery, Backup/Verify/Restore, 1.x import, Emergency Lock and Self-Destruct.
- Added technical educational sections explaining the Argon2id-protected key envelope, random 256-bit DEK, AES-256-GCM authenticated encrypted files, main-process key ownership, narrow IPC, transaction journals, concurrent operation ordering, checksums versus independent password verification, privacy limits, and power-loss caveats.
- Refreshed GitHub README's top-level release notes to distinguish the **2.6.10 package on `master`** from the **2.6.119 stacked development functionality**, with 2.6.120 being a documentation-only patch.
- Updated the generic portable application filename examples so they no longer misleadingly refer to the 2.6.6 binary.
- Preserved existing in-depth icon catalog and earlier release documentation in GitHub README.

The new PDF is generated by `npm run docs:pdf -- release/windows/app/README.pdf` as part of the Windows portable artifact workflow. Test on the exact commit with cross-platform GitHub Actions. **Do not merge without explicit owner approval.**
