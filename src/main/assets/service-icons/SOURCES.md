# Packaged service brand artwork

SafeLedger bundles these SVG files for its **offline-only** Profile icon picker. No
icon service, browser CDN, remote CSS, tracking pixel, or runtime network request
is involved. Files were reviewed before being committed. SafeLedger does not
claim ownership of the company marks, and displaying a mark does **not** imply
affiliation or endorsement.

The eBay, Proton and Amazon single-color artwork uses the corresponding
brand's catalog accent as its SVG fill. The original contour/path remains intact.
Chain Games continues to use existing SafeLedger-owned theme-specific artwork.

Brand trademarks and brand usage guidelines are separate from SVG licenses.
If a brand owner asks for a correction or removal, update this catalog's reviewed
file and provenance together. Do not download arbitrary URLs or store SVG
markup in Profile data. Profile icons persist only a canonical service name;
the renderer resolves it to a fixed reviewed file.
